# Awesome-Realtime-Translator

面试实时字幕。听懂英文面试官。

**[下载与官网](https://yangli-0409.github.io/Awesome-Realtime-Translator/)** ·
[English README](README.md) · [工程笔记](docs/ENGINEERING.zh-CN.md) ·
[Windows 版](windows/README.md)

它听你电脑正在放出来的声音，在屏幕顶部的悬浮窗里显示原文字幕和中文翻译。
全程在你自己这台机器上完成，不加入会议，对方看不到任何东西。

**只帮你听懂，不替你回答。** 没有「建议答案」功能，以后也不会有。

---

## 它做什么

**边听边出字。** 原文一个词一个词往前推，整句说完才给译文；译文一旦出现就不再改写，
不会在你读的时候整行乱跳。

**对方看不到。** 字幕窗不会出现在任何录屏或屏幕共享的画面里，连你自己录屏也录不到它。
不是「检测到你在共享就躲起来」，是它从一开始就录不进去——共享整个桌面也一样。

**全程不联网。** 听写和翻译都用你这台 Mac 自己的能力。它没有联网的能力，断网照样工作。
这不是口头承诺，是它本来就做不到。

**不留痕。** 声音听过就丢，任何时候都不写进硬盘。文字默认也不保存；真想留，
可以一键复制，或者把这一场的中英对照导出成 Markdown。

**不打扰你。** 不抢键盘焦点，你在 Zoom 里打字不会被打断。没有 Dock 图标。
可以开鼠标穿透当它不存在。别的应用全屏时它还在最上层，位置随便拖。

**看着顺眼为止。** 三种显示模式（双语 / 只看原文 / 只看译文）、字号、透明度、
显示行数、出字快慢，都能调。

## 有多快

| | |
| --- | --- |
| 原文 | 落后对方约一秒 |
| 译文 | 对方说完一句之后约半秒出现 |
| **端到端** | 从他说完到你看懂，**约 1.5 秒** |

其中约一秒是苹果本机语音引擎在判断「刚才听到的是什么」，软件改不了，换台更贵的 Mac
也不会更快。软件能决定的是**节奏**：不是每秒蹦出一批词，而是把它们摊开匀速放出来，
让字看起来是连续流动的。这个节奏是设置里的一个滑块（0.3~1.0 秒，默认 0.5）——
调低更跟手但能看出一跳一跳，调高更顺滑但滞后更多。

## 安装

需要 **macOS 26 及以上**。通用二进制（Apple 芯片 / Intel），0.8 MB。

1. [下载](https://yangli-0409.github.io/Awesome-Realtime-Translator/AwesomeRealtimeTranslator-0.1.0.zip)、
   解压，拖进「应用程序」。
2. **第一次打开用右键。** 系统会说「无法验证开发者」，因为这个版本背后没有苹果开发者证书。
   右键点它 → 选「打开」→ 再确认一次。只需要做一次。
3. 允许**「屏幕与系统音频录制」**。macOS 把「听电脑正在放的声音」放在这一项底下，
   没有单独的「系统声音」选项可以给。它只拿声音，画面每一帧都直接丢掉。
4. 点引导页上的**「立即重启应用」**。刚给的权限要重开一次才生效。
5. 字幕窗出现在屏幕顶部中间，点 ▶ 开始听。

第一次开始会话时，系统可能要下载语音模型和翻译语言包。语言包也可以提前在
「系统设置 › 通用 › 语言与地区 › 翻译语言」里装好。

## 已知限制

- **只能装在 macOS 26 及以上。** 它靠的是旧系统没有的本机听写和翻译能力。
- **慢约 1.5 秒。** 这是语音引擎的速度上限，不是没调好。
- **它听得到面试官，听不到你自己。** 只采集系统声音，不采麦克风。这是故意的。
- **每次更新完要重新授权一次。** 没有苹果开发者证书，系统会把新版本当成另一个应用。
- **只认真测过英语 → 中文。** 法语、德语、日语、西班牙语能选，但没实测过效果。
- **合规是你自己的事。** 不同国家和地区对「会议正在被转写」的告知义务不同。
  本应用不录音、不存文件，但是否需要告知对方，请你自行确认。

```bash
xcodegen generate && open AwesomeRealtimeTranslator.xcodeproj
```

```bash
xcodebuild -project AwesomeRealtimeTranslator.xcodeproj -scheme AwesomeRealtimeTranslator -destination 'platform=macOS' test
```

工程文件由 `project.yml`（XcodeGen）生成，`.xcodeproj` 也一并提交，没装 xcodegen
也能直接打开。环境要求：macOS 26.0+、Xcode 26+。

```

├── App/           管道装配、菜单栏、全局快捷键、App 入口

├── Permissions/   权限检测与首次引导
```

## 已经验证的 / 还没验证的

诚实分界线，别把下面两栏混着看。

**已验证**

- Swift 6 完全并发检查下零错误编译。
- 断句的 27 个单元测试全过，含一段端到端事件脚本。其中 3 个 bug 是测试逮出来的。
- Release 配置打包成 `.app`，启动后进程存活、无崩溃报告。
- 本机跑通整条管道：采集 → 识别 → 断句 → 翻译 → 字幕窗，反复运行日志无报错。

**没验证（需要你本机跑一次）**

1. 真人语速下的准确率和延迟。上面的 ~1.5 秒是用合成语音量的，语速太均匀。
2. 翻译语言包未安装时的下载流程。
3. 60 分钟连续运行的稳定性与 CPU 占用。
4. 插拔耳机 / 切换输出设备后的自动恢复。
5. 中文作为**源语言**时的识别效果。
6. 全局快捷键在没有输入监控权限时还能不能用。

## Windows 版

已经写完，功能和 macOS 版对齐，代码在 [`windows/`](windows/README.md)。

**[下载 Beta（389 MB）](https://github.com/yangli-0409/Awesome-Realtime-Translator/releases/tag/v0.1.0-windows-beta)** · 需要 Windows 10 2004 及以上

标 Beta 是因为**这个版本从来没有在 Windows 上运行过**。移植是在一台 Mac 上完成的：
代码能编译成真正的 Windows 可执行文件（x64 和 arm64 都验证过），83 个单测全过，
翻译也在开发机上用真实模型实测过。缺的是最关键的两件事——
能不能抓到系统声音、字幕窗是不是真的从屏幕共享里消失。

**共享屏幕前请自己用会议软件的共享预览确认一次。**

| | macOS | Windows |
|---|---|---|
| 系统音频 | ScreenCaptureKit | WASAPI loopback |
| 需要权限 | 屏幕与系统音频录制 | **不需要** |
| 语音识别 | 系统 SpeechAnalyzer | 自带 whisper.cpp |
| 翻译 | 系统 Translation 框架 | 自带 OPUS-MT ONNX |
| 安装包 | 0.8 MB | 约 540 MB |

体积差在于 Windows 没有系统级的识别和翻译，模型得自己带。
