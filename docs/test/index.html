共享自测页

开会前花一分钟,自己看一眼:共享屏幕的时候,字幕窗是不是真的不在对方的画面里。
全程只在你的浏览器里运行,画面不会上传到任何地方。
在你跑字幕宝的那台电脑上打开这个页面,用 Chrome 或 Edge。手机上测不了。

↑ 这条粉色带子是检测用的参照物,别遮住它 ↑

怎么测

  1. 先把字幕宝打开,让字幕窗出现在屏幕顶部正中。不用点开始,出现就行。
  2. 在字幕窗的设置里确认「屏幕共享时隐藏字幕窗」是打开的(默认就是开的)。
  3. 回到这个页面,点「开始检测」,在弹出的选择器里选「整个屏幕」。
  4. 看下面的结果和预览。预览里是什么,对方就看到什么。

怎么判断

你看到的意思
粉色带子在,字幕窗不在 通过。画面确实抓到了你的屏幕,而字幕窗没被抓进去——这正是想要的结果。
粉色带子在,字幕窗也在 不要用。隐藏没生效,对方会看到你的字幕。先去设置里确认开关是开的;还是不行就别在共享时用它。
粉色带子不在 这次不作数。说明画面里根本没有这个页面——可能你选的不是「整个屏幕」,或者浏览器窗口被挡住/最小化了。重测一次。
为什么要盯着那条粉色带子。 如果共享根本没抓到你的屏幕(选错了共享对象、画面是黑的),预览里同样看不到字幕窗—— 但那不是「隐藏成功」,是「什么都没测」。这两种情况长得一模一样,而误判的代价是 你带着一个对方看得见的字幕窗去面试。所以先确认参照物在,结论才成立。

这个测试测不到什么

这个页面用的是网页版会议用的那套屏幕共享接口。结论对 Chrome / Edge 里的 Google Meet、Zoom 网页版、飞书网页版、腾讯会议网页版都成立。

桌面客户端是另一回事。Zoom、Teams、飞书的桌面版有自己的抓屏方式, 有的会绕过系统的「不要截取此窗口」标记。要用桌面客户端的话,请用它自带的共享预览 再确认一次,或者拿另一台设备入会看一眼。

录屏软件、截图工具同理:换一个工具就该重测一次。
