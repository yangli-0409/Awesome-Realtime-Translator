它做什么，不做什么

产品边界只有一句话：只帮你听懂，不替你回答。

实时

边听边出字

原文一个词一个词往前推，整句说完才给译文。译文一旦出现就不再改写，不会在你眼前反复跳。

本机

全程不联网

听写和翻译都用你这台 Mac 自己的能力完成。它没有联网的能力，断网也照样工作——这不是承诺，是它本来就做不到。

不打扰

不抢焦点，不占 Dock

你在会议软件里打字不会被打断。没有 Dock 图标，可以开鼠标穿透当它不存在，别的应用全屏时它也还在最上层。

不留痕

不录音，不存文件

声音听过就丢，任何时候都不写进硬盘。文字默认也不保存；真想留，可以一键复制或导出这一场的中英对照。

可调

看着顺眼为止

三种显示模式（双语 / 只看原文 / 只看译文）、字号、透明度、显示行数、出字快慢，都在设置里拖滑块。

克制

不生成回答

没有「建议答案」功能，以后也不会有。面试是你在面，它只负责让你听清对方说了什么。

有多快

不说「极速」「零延迟」这种话，给个你能对得上的数。

  • 原文落后对方约一秒。他说到第五个词的时候，你大概看到第二三个词。
  • 译文在他说完一句之后约半秒出现。算下来，从他说完到你看懂，大约 1.5 秒。
  • 这个速度是苹果的听写能力决定的，不是软件偷懒，也不会因为换台更贵的 Mac 变快。

实际用起来的感受是：对方正常语速讲话时，字幕是连续往前流的，不会一段一段跳。 他讲完一句你低头看译文的那半秒，刚好是你准备开口的半秒。

安装

大约两分钟。中间会让你重启一次应用，这是 macOS 的正常流程，不是出错了。

  1. 下载解压，拖进「应用程序」
  2. 第一次打开用右键

    系统会说「无法验证开发者」，因为我没有买苹果的开发者证书。在「应用程序」里右键点它 → 选「打开」，再确认一次就好。只需要这么做一次。

  3. 允许「屏幕与系统音频录制」

    macOS 把「听电脑正在放的声音」放在这一项权限底下，没有单独的选项可以给。它只拿声音，不截图、不录画面。

  4. 点「立即重启应用」

    刚给的权限要重开一次才生效。引导页上有这个按钮，点一下就行。

  5. 完成

    字幕窗出现在屏幕顶部中间，点左上角 ▶ 开始听。

Windows 版

已经写完，功能和 Mac 版一样。但还没有人在 Windows 上真正跑过它，所以现在只开源码，不放下载。

  • 做完了什么。听系统声音、边听边出字、整句翻译、字幕窗对屏幕共享隐藏、 不抢焦点、鼠标穿透、托盘、全局快捷键、设置、复制导出——Mac 版有的都有。
  • 为什么还不放下载。它是在一台 Mac 上写完的。代码能编译成真正的 Windows 程序， 断句和翻译也都在开发机上实测过，但「能不能抓到系统声音」和「字幕窗是不是真的 从屏幕共享里消失」这两件最关键的事，必须在 Windows 上跑一次才算数。 在那之前放下载按钮不负责任。
  • 它会比 Mac 版大很多。约 540 MB，因为 Windows 没有系统自带的语音识别和翻译， 模型得自己带。Mac 版 0.8 MB 是因为这两样 macOS 都有。
  • 有一个地方反而更好。Windows 版不需要任何系统权限， 双击就能用，也没有 Mac 那个「每次更新都要重新授权」的麻烦。
  • 想现在就试。装 .NET 10 SDK，然后在仓库的 windows/ 目录里跑 tools/fetch-models.ps1 和 tools/package.ps1。 跑通了欢迎来开 issue 告诉我结果——那正是现在最缺的一步。

已知限制

这些是现在就知道的，写在这里省得你踩。

  • 只能装在 macOS 26 及以上。它靠的是 macOS 26 才有的本机听写和翻译能力，旧系统装不上。
  • 慢约 1.5 秒。这是苹果听写能力的速度上限，换电脑也不会更快。
  • 只听电脑放出来的声音，不听麦克风。也就是说它听得到面试官，听不到你自己。这是故意的。
  • 每次更新完要重新授权一次。因为没有苹果开发者证书，系统会把新版本当成另一个应用。
  • 只认真测过英语 → 中文。法语、德语、日语、西班牙语在设置里能选，但我没实测过效果。
  • 合规提示：不同国家和地区对会议录音 / 转写的告知义务不同。本应用不录音、不保存音频，但文字转写是否需要告知对方，请你自行确认。

常见问题

为什么要「屏幕录制」权限？会不会偷看我的屏幕？

macOS 把「听电脑正在放的声音」归在「屏幕与系统音频录制」这一项底下，没有单独的「系统声音」权限可以申请，所以只能要这一项。它只拿声音，画面直接扔掉，不截图也不录屏。

对方真的看不到吗？

看不到。字幕窗被设成对所有录屏和屏幕共享都不可见，连你自己录屏都录不到它。不过第一次用之前，建议你先用会议软件的共享预览自己看一眼——少数软件直接抓屏幕原始画面，不守这个规矩。

它会把我的面试内容传到云端吗？

不会，而且不是「承诺不传」——它根本没有联网的能力，连不上任何服务器。你可以拔掉网线试试，功能完全不受影响。

为什么译文是一整句出现，原文却是一个词一个词出现的？

故意这么做的。中文和英文语序不一样，边听边翻的话译文会被反复改写，整行字乱跳，比多等一秒难受得多。所以只有一句话说完了才翻，翻出来就不再改。

能帮我生成回答吗？

不能，以后也不会做。它只帮你听懂，不替你回答。

会不会很耗电？

听写和翻译都跑在 Apple 芯片自己的加速单元上，比那些把声音传上云的方案省电。但我还没测过连续一小时的耗电和发热，这点先别当成已验证的结论。

可以用在上课、看视频、听播客上吗？

可以。它不认得「这是面试」，只要是你电脑里放出来的声音，它都能听。只是所有的设计取舍都是围绕面试做的：低调、不留痕、不抢焦点。
